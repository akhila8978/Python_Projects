## 📌 What's Inside

This repo is organized by Python concept, with each project demonstrating a specific skill:

| Concept | Topics Covered |
|---------|---------------|
| 🔢 Variables & Data Types | Strings, integers, floats, booleans, type casting |
| 🔁 Loops | for loops, while loops, list comprehensions, nested loops |
| ⚙️ Functions | Parameters, return values, *args/**kwargs, lambda functions |
| 🏗️ OOP | Classes, objects, inheritance, encapsulation, polymorphism |
| 📂 File Handling | Read/write CSV, text files, JSON, exception handling |

## 🚀 Getting Started

```bash
git clone https://github.com/akhila8978/Python_Beginner_Projects.git
cd Python_Beginner_Projects

# Run any project
python <project_file>.py
```

**Requirements:** Python 3.8+ (no external libraries needed)
